# fastapi-book-okf

An **[OKF](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) knowledge bundle** of [https://fastapi.tiangolo.com/tutorial/](https://fastapi.tiangolo.com/tutorial/) — ready for agents to read and for you to chat with.

```bash
pip install okf-kit
okf get fastapi-book
okf chat fastapi-book --provider ollama
```

Or use it straight from this repo (the bundle is in `fastapi-book/`):

```bash
okf chat fastapi-book --provider ollama
okf visualize fastapi-book
```

Built and kept fresh with [okf-kit](https://github.com/vinodborole/okf-kit).
